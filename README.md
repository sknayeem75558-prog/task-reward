# TaskEarn
GitHub Pages + Supabase Task & Reward starter.

Setup:
1. Supabase SQL Editor-এ schema.sql একবার চালাও।
2. config.js-এ নিজের Project URL এবং Publishable/anon key বসাও।
3. সব ফাইল GitHub repository root-এ upload করো।
4. GitHub Pages চালু করো।
5. Register করো।
6. Supabase Table Editor > profiles-এ নিজের row-এর is_admin=true করো।
7. admin.html খুলে task তৈরি করো।

কখনো service_role/secret key frontend-এ দিও না।
Admin-এর Mark Paid শুধু status বদলায়; নিজে থেকে টাকা পাঠায় না।
